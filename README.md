# Java Tic-Tac-Toe

A simple console-based Tic-Tac-Toe game developed in Java.

## Description

This project is a two-player Tic-Tac-Toe game that runs in the console. Players take turns placing `X` and `O` on a 3×3 game board. The program checks for a winner or a draw after each move.

## Features

* Two-player gameplay
* 3×3 game board
* Input validation
* Winner detection
* Draw detection
* Console-based interface

## Technologies

* Java
* IntelliJ IDEA

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Open `TicTacToe.java`.
4. Run the `main()` method.
5. Enter the row and column numbers from `1` to `3`.

### Example

```text
=== TIC-TAC-TOE ===

   1   2   3
1  X | O |  
  ---+---+---
2    | X |  
  ---+---+---
3  O |   | X

Player X wins!
```
